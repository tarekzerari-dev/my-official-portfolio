01 — Overview

High-speed luxury commerce without bloat

Le Gentleman was engineered to deliver an editorial luxury shopping experience for Ralph Lauren linen shirts across Algeria while operating on a zero-infrastructure-cost, fault-tolerant serverless pipeline. Every interaction — from instant French/Arabic layout switching to real-time 58-wilaya delivery tariff calculation — runs in sub-millisecond native JavaScript with zero third-party runtime dependencies.

Engineering Objective Instant storefront load, dynamic wilaya pricing, and serverless order ingestion
My Scope Full-Stack Implementation — Modular storefront JS, bilingual i18n RTL engine, validation, and Apps Script webhook backend
02 — The Problem

Mobile friction & regional shipping complexity

Algerian e-commerce buyers frequently abandon heavy multi-step WooCommerce or Shopify checkouts due to slow mobile loading over 4G networks, missing Arabic RTL support, unvalidated local phone formats, and opaque shipping costs across 58 distinct wilayas. Store operators also needed instant order logging without paying recurring SaaS server fees.

03 — System Architecture

Deterministic modular pipeline

Structured with decoupled configuration, internationalization, and state scripts loaded in deterministic order without build-tool overhead.

Centralized Store Config

Single-source js/config.js defining catalog SKUs, pricing, sizing matrices, and dynamic delivery rates across all 58 Algerian wilayas.

Live RTL i18n Engine

Custom dictionary system (js/lang.js) persisting FR/AR locale in localStorage and atomically flipping document directionality.

Google Apps Script Webhook

Serverless doPost handler in Code.gs ingesting validated JSON payloads directly into structured Google Sheets order ledgers.

Edge Security Headers

Strict CSP, cache-control rules, and clean rewrite routing configured via netlify.toml with custom error handling.

04 — Checkout & Fulfillment

Smart checkout & validation flow

Engineered to take a customer from product selection to confirmed order in seconds without account walls.

01

Query-driven product pre-selection

Selecting any shirt passes order.html?product={id}, automatically locking the garment preview, unit price, and variant context on arrival.

02

Algerian phone & 58-wilaya tariff calculator

Enforces regex validation for Algerian mobile prefixes (05, 06, 07) while recalculating live subtotals and regional shipping fees on selection.

03

Resilient opaque webhook submission

Submits payloads cleanly to Apps Script endpoints with duplicate-submission locking, auto-header provisioning, and smooth redirect to confirmation.

05 — Bilingual RTL Engineering

Instant French ↔ Arabic layout mirroring

Clicking the language toggle dynamically swaps every UI string, updates semantic dir="rtl" attributes on the root node, mirrors navigation flows, and persists customer language preference across checkout and confirmation pages.

07 — Reflection

Key engineering takeaways

Performance by subtraction

Eliminating framework overhead yielded instantaneous page transitions on slower regional cellular networks while keeping maintenance effortless.

Pragmatic serverless workflows

Pairing a static Netlify edge storefront with Google Apps Script webhooks created a reliable order ledger system with zero monthly hosting costs.
