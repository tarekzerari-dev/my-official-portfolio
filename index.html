About Me

Bridging engineering rigour with human-centered product craft.

I'm Tarek Zerari, a Computer Science Engineering student at ESI Algiers and an independent digital product builder. I thrive at the exact intersection where user experience meets technical constraints.

Methodology

How I Build Products

A deliberate, 4-step framework turning ambiguous problems into shipping software.

01

Discover & Model

Unpack domain challenges, map user personas, and establish the core data model and entity relations before sketching a single pixel.

02

System & Tokens

Define reusable design tokens, typography scales, responsive grids, and RTL compatibility rules to maintain visual and functional consistency.

03

Prototype & Validate

Craft interactive high-fidelity prototypes to stress-test real workflows, discover edge cases, and eliminate friction before writing heavy code.

04

Code & Ship

Build the frontend and backend with TypeScript, Next.js, and Supabase, enforce database security (RLS), test performance, and deploy to production.
