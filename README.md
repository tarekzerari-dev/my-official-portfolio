# 🎨 Tarek Zerari - UI/UX & Frontend Portfolio

A personal design and frontend development showcase presenting interactive case studies, design specifications, and live demonstrations for educational, healthcare, and community applications.

---

## 🌟 Featured Case Studies

1. **Ecours**:
   - Smart course & QR-code attendance management system.
   - Comprehensive UI/UX design specifications, user flow diagrams, and interactive web views (`ecours.html` / `ecours-ar.html`).

2. **Sanad (سند)**:
   - Community support & student solidarity platform.
   - Bilingual case study detailing accessibility, empathy-driven UX, and clean layouts (`sanad.html` / `sanad-ar.html`).

3. **HealthTrack**:
   - Healthcare and patient tracking interface.
   - Patient vitals, appointment scheduling, and responsive healthcare dashboards (`healthtrack.html` / `healthtrack-ar.html`).

4. **LMCS**:
   - Laboratory and academic department information portal (`lmcs.html` / `lmcs-ar.html`).

---

## ✨ Features

- **🌍 Bilingual Support**: Full English and Arabic (RTL) case studies and landing page (`index.html` & `index-ar.html`).
- **📱 Fully Responsive**: Fluid animations, CSS Grid & Flexbox, optimized across mobile, tablet, and ultra-wide screens.
- **📄 Comprehensive Design Documentation**: Includes full UI/UX design specifications, color palettes, and typographic hierarchies.

---

## 🚀 Live Preview / Local Setup

Simply clone the repository and open `index.html` in any modern web browser or serve with a local static server:

```bash
git clone https://github.com/tarekzerari-dev/ui-ux-portfolio.git
cd ui-ux-portfolio

# Optional: serve with Python or npx
python -m http.server 8080
# or
npx serve .
```
